ABOUT
- A Hundred Acre Wood themed web operating system.

CORE FEATURES/APPS
- Interactive walkthrough

- Time widget
- Weather-checking widget
- Battery widget (may not work for most browsers besides Chromium ones + Opera)

- Notes app/Media title collection with separate tabs for: books, movies, and quotes w/ suggestions from Owl character
- Music player
- Goal setter
- Mood support from Piglet character
- Timer
- 'Terminal' with settings-like commands for the page

TECH STACK
- Built with: HTML-5, CSS-3, Vanilla JS (ES6+), and OpenWeatherMap APIs
- Deployed with: Netlify
- Version control: Github
